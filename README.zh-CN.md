# Pocket Groove · 口袋鼓房

[English](README.md) | 简体中文

**[在线试玩](https://derekllr.github.io/pocket-groove/)** · [反馈问题](https://github.com/Derekllr/pocket-groove/issues)

一个轻量的浏览器鼓机与节奏练习工具。点亮格子编节奏，用键盘打鼓，导出自己的声音。支持中英文切换，全部鼓声实时合成，无需注册、安装依赖或下载音频素材。

## 开始玩

下载仓库后，直接用 Chrome 或 Edge 打开 `dist/index.html`，点击“开始播放”。右上角可切换中文 / English，选择会保存在当前浏览器。

- 六轨、16 格、4/4 拍，普通点击切换重击，Shift + 点击切换轻击。
- 40–220 BPM、摇摆、Tap 定速、节拍器、每轨静音 / 独奏 / 音量。
- Rock、Lo-fi、House、Funk 四套起始节奏，以及镲片与加花变奏。
- A / S / D / F / G / H 即兴打鼓，空格播放或停止。
- 渐速练习每 4 次循环加速，直到设定目标。
- 浏览器自动保存，支持 JSON 工程导入导出、四小节 WAV 导出。

## 本地开发

需要 Node.js 20+，无第三方依赖。

```sh
npm test
npm run build
npm start
```

在 `http://127.0.0.1:4173` 预览。修改 `src/` 后重新构建。`dist/index.html` 是打包输出，包含所有脚本与样式，可离线打开。

## 实现思路

- 使用 Web Audio 的音频时钟提前安排发声，界面动画不负责节拍计时。
- 合成器组合振荡器、噪声与滤波器，闭镲会截断开镲。
- 摇摆调整相邻两个十六分音符的时长，但保持整小节时长。
- WAV 使用相同合成器离线渲染，输出单声道 PCM16，包含尾音，不包含节拍器或渐速。
- 中英文词典与动态标签翻译集中在 `src/i18n.mjs`，语言选择独立保存，不修改工程数据。

## 当前边界

这是单小节循环鼓机，尚不支持多小节歌曲编排、鼓谱 PDF 识别、麦克风录音或演奏评分。浏览器切到后台会暂停播放。不同设备的音频延迟和听感仍需实际测试。本地文件页面的存储行为因浏览器而异，重要工程请导出备份。
